# Logo sources

All marks are trademarks of their owners, shown here only to identify where I worked or studied.
Each file was produced by `scripts/logos.mjs`. The script keeps only the vector geometry and
renders it single-color in `currentColor` (ink tone on the site).

| File | Source | Notes |
|---|---|---|
| `renphil.svg` | `design-references/renaissance-philanthropy.svg` (supplied) | Mark only, no wordmark |
| `bah.svg` | https://www.boozallen.com/assets/home/images/homepage/bah-logo-trademark.svg | Current "Booz Allen" wordmark; ® glyph dropped |
| `spectech.svg` | https://spec.tech/logo.svg | Geometric mark, cropped from mark + wordmark |
| `newlab.svg` | Newlab site header (`Newlab_Logo_Black.svg` on their Webflow CDN) | Wordmark; no standalone mark exists |
| `4cair.svg` | https://4cair.com/wp-content/uploads/2021/03/4C-Air-Logo-Official.png | Official logo exists only as a raster; traced to vector with potrace |
| `berkeley.svg` | https://brand.berkeley.edu/icon.svg | B monogram (public secondary asset), blue square removed. The primary logo needs 200 px minimum and the seal needs permission |
| `cornell.svg` | https://brand.cornell.edu/assets/images/downloads/logos/bold_cornell_seal_simple/bold_cornell_seal_simple.svg | Bold simple seal, one-color |
